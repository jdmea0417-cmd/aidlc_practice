# UI Specification — A / B / C 상세 사용자 흐름 v2

> 원본: "SCD 소통 코칭" UI 시안(A/B/C 상세 사용자 흐름 v2). 화면 구성과 흐름은 시안 기준이며,
> 세부 문구는 시안 해상도 한계로 기획서 내용에 맞춰 재구성했다. 이미지가 함께 제공된 경우 레이아웃은 이미지를, 문구·동작은 이 문서를 따른다.

## 1. 공통

- 모바일 웹, 기준 폭 375px. 상단: 뒤로가기 + 화면 제목 + 단계 표시. 하단: 주요 버튼 1개(전폭).
- 하단 탭 4개: **홈 / 대화 돌아보기 / 연습 / 기록**
- 색 체계: 헤더 네이비, **A 흐름(실제 대화) = 초록 계열 버튼**, **B 흐름(모의 대화) = 보라 계열 버튼**, 보류·주의 = 노랑 박스, 잘한 장면 = 초록 체크
- 모든 비동기 화면은 `로딩 / 성공 / 실패(재시도 버튼) / 비어 있음` 상태를 가진다.
- 문구 규칙: `01_vision.md` 7장 금지 표현을 지킨다. 존댓말, 짧은 문장.

## 2. 흐름 요약

```
A1 홈 ─┬─> A2 실제 대화 가져오기 ─┬─ 파일 선택 ─────┐
       │                          └─ A2-R 새로 녹음 ─┴─> A3 대화 내용 확인 ─> A4 대화 돌아보기(리포트) ─> A5 연습 목표 선택
       │                                                                                                   │
       └─> B1 연습 목록 <────────────────────────────────────────────────────────────────────────────────────┘
             └─> B2 연습 준비 ─> B3 모의 대화 ─(힌트)─> B4 도움 받기 ─> B3 재시도 ─> B5 연습 결과 ─> C1 / B1
C1 나의 기록 ─> C2 목표 상세 / C3 연습 기록 상세 / C4 실제 대화 기록 상세
C5 자료·공유 설정
```

**연결 조건**: A5에서 선택한 `goalId`와 `sourceEventId`는 B1–B5, C2까지 URL 파라미터 또는 상태로 유지된다.

## 3. A. 실제 대화를 돌아보고, 다음 연습을 고릅니다

### A1 홈 — "어떤 대화를 함께 살펴볼까요?"
- 카드: **실제 대화 돌아보기**(→A2), **모의 대화 연습하기**(→B1), 진행 중인 목표 카드(있을 때, →B1)
- 최근 기록 1–2건 요약(→C1)
- 첫 방문: 서비스 안내(진단이 아님, 녹음·데이터 처리 안내, 이용 한계) 동의 후 진입
- 관련: F01, F06

### A2 실제 대화 가져오기 — "대화를 가져오는 방법을 먼저 선택해요"
- 선택 카드 2개: **녹음 파일 선택**(파일 업로드) / **새로 녹음하기**(→A2-R)
- 맥락 입력: 누구와(관계), 어디서(장소), 무엇을 하려고(목적), 내가 원했던 것(사용자 목표). 각 항목에 **"잘 모르겠어요"** 선택지 → 미상 저장
- 녹음 동의 확인 체크: "대화에 참여한 사람에게 녹음을 알렸어요"
- 업로드 후 처리 상태: 업로드 중 → 전사 중 → 완료 / 실패(다시 시도)
- 버튼: "대화 내용 확인하기" (초록)
- 관련: F01, F02

### A2-R 새로 녹음하기
- 큰 마이크 버튼, 경과 시간(예: 00:18), 최대 5분 안내
- 버튼: 일시정지 / 녹음 끝내기 / 다시 녹음
- 녹음 끝 → 업로드 → A3
- 권한 거부 시 안내 + 파일 선택으로 전환

### A3 대화 내용 확인 — 전사 확인
- 발화 목록: 화자 라벨(나/상대/모름), 시간, 텍스트
- **불명확 구간 강조**(빨강/주황 표시 "잘 안 들린 부분") + 수정 입력
- 발화별 액션: 텍스트 수정, 화자 변경, "분석에서 빼기"
- 상단 요약: 확인한 맥락 / 아직 모르는 맥락 구분 표시
- 수정 시 정정 이력 저장
- 버튼: "이대로 분석하기" (초록)
- 관련: F01, F02, F07

### A4 대화 돌아보기 — 근거 기반 리포트
- 상단: 대화 상황 요약(관계·장소·목적), **분석할 수 있었던 범위**
- 섹션 1 **잘한 장면**(초록 체크): 장면 설명 + 근거 발화 인용
- 섹션 2 **어려움이 보인 장면**: 무엇이 관찰됐는지, 판단 이유, **이렇게 말해볼 수도 있어요**(여러 대응)
- 섹션 3 **분석을 보류한 부분**(노랑 박스): 보류 사유(기회 없음/맥락 부족/전사 불명확)
- 각 장면의 버튼: **근거 보기**(해당 발화로 스크롤·강조), **맥락 수정**(→A2 맥락 입력), **이 목표 연습**(→A5 선택 상태)
- "분석이 이상해요" 수정 요청 버튼
- 종합점수·등급 표시 없음
- 관련: F03

### A5 연습 목표 선택 — "무엇을 연습해볼까요?"
- 추천 목표 카드 1–3개: 목표 이름, **추천 이유**(원인 장면 링크), 행동 묶음
- 선택된 카드는 보라 테두리 강조. 사용자가 다른 목표로 변경 가능
- "지금은 연습하지 않을래요" 선택지
- 버튼: **"이 목표로 연습 시작"**(보라, →B1 또는 B2)
- 저장: 추천 목록, 사용자 선택, 변경 여부
- 관련: F04

## 4. B. 모의 대화에서 직접 시도하고, 필요한 도움을 받습니다

### B1 연습 목록
- 상단 강조 카드(보라): 현재 목표 + 연결된 실제 대화 장면 요약 + "지금 연습하기"
- 목록: 같은 목표의 다른 상황 연습, 검토된 일반 연습("실제 경험 기반이 아닌 일반 연습" 라벨)
- 관련: F05

### B2 연습 준비 — 상황 소개
- 상황 설명(예: "친구와 함께 그림을 그리기로 했어요"), 상대 역할, 이번 연습 목표
- 정답·모범 문장은 **미리 보여주지 않음**
- 버튼: "준비됐어요"(보라), "다른 상황으로 바꾸기"
- 관련: F05

### B3 모의 대화
- 채팅 말풍선(상대=AI, 나=사용자), 텍스트 입력창
- 보조 버튼: **힌트 받기**(→B4), **잠깐 멈추기**(중단/재개)
- 첫 응답은 도움 없이 입력(독립 시도로 기록)
- 관련: F05

### B4 도움 받기 — "어떤 말을 하면 좋을까요?"
- 단계형 힌트(누를 때마다 다음 단계):
  1. 주의 단서: "상대가 방금 무엇을 물어봤는지 다시 볼까요?"
  2. 정보 힌트: "상대가 모르는 정보를 덧붙이면 좋아요"
  3. 예시: 기능적으로 가능한 대응 2–3개
- 버튼: "다시 해볼게요"(→B3, 재시도로 기록)
- 제공한 힌트 단계·내용·횟수 기록
- 관련: F05

### B5 연습 결과
- **처음 시도**와 **다시 시도**를 나란히 표시(덮어쓰지 않음)
- 받은 도움 종류, 목표 행동이 나타난 발화 강조
- 문구 예: "도움을 받은 뒤 인물을 설명하는 말을 덧붙였어요"
- 버튼: "다음 연습"(→B1), "기록 보기"(→C3), "다른 목표 고르기"(→A5)
- 관련: F05, F06

## 5. C. 기록·설정과 이어지는 상세 화면

### C1 나의 기록
- 필터 탭: 전체 / 실제 대화 / 모의 대화
- 목록 항목: 날짜, 유형 배지, 연결 목표, 요약 한 줄
- 목표별 추이 카드: 독립 수행 / 도움 후 수행 **분리 표시**, 기록 부족 시 **"아직 비교하기엔 기록이 부족해요"**
- **다음 코칭 추천** 카드: 추천 이유 + 근거 기록 링크
- 관련: F06

### C2 목표 상세 — "지금 무엇을 연습하고 있는지 봐요"
- 목표 설명, 원본 실제 대화 장면(→C4), 연습 시도 이력 타임라인
- 반복 패턴 / 잘 된 조건 표시(기록 충분할 때만)
- 버튼: 목표 변경, 이 목표 그만하기
- 관련: F04, F06

### C3 연습 기록 상세
- 시도 순서, 독립/도움 후 구분, 힌트 단계, 중단·재개 여부, 사용된 시나리오 원형·변형 정보
- 관련: F05, F06

### C4 실제 대화 기록 상세
- 전사(정정 반영본) + 정정 이력 보기
- 당시 리포트, **재검토 필요** 배지(전사 정정 후)
- 분석 기준·모델 버전 표시(작게)
- 버튼: 다시 분석하기, 이 기록 삭제
- 관련: F03, F06, F07

### C5 자료·공유 설정
- 보호자·지원자 열람 권한(끄기/요약만/전체)
- 원음 보관 기간, 원음만 삭제
- 기록 삭제 요청: 삭제될 연결 항목 미리보기(전사, 판정, 연결된 연습, 추천) → 확인 → 처리 상태
- 서비스 안내 다시 보기(진단 아님, 데이터 처리)
- 관련: F07

## 6. 화면 ↔ API (초안)

|---|---|
| A2/A2-R | `POST /api/conversations` (multipart), `PUT /api/conversations/{id}/context` |
| A3 | `GET /api/conversations/{id}/transcript`, `PATCH /api/utterances/{id}` |
| A4 | `POST /api/conversations/{id}/assessments`, `GET /api/conversations/{id}/report` |
| A5 | `GET /api/conversations/{id}/goal-recommendations`, `POST /api/goals` |
| B1–B2 | `GET /api/goals/{id}/scenarios`, `POST /api/practice-sessions` |
| B3–B4 | `POST /api/practice-sessions/{id}/attempts`, `POST /api/practice-sessions/{id}/hints` |
| B5/C3 | `GET /api/practice-sessions/{id}/result` |
| C1/C2 | `GET /api/records`, `GET /api/goals/{id}` , `GET /api/recommendations/next` |
| C4 | `GET /api/conversations/{id}/history` |
| C5 | `PUT /api/sharing`, `POST /api/deletion-requests` |
