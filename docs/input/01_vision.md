# Vision — SCD 소통 코칭 (테스트 MVP)

## 1. 한 문단 요약

사회적 의사소통장애(SCD)로 대인관계와 일상생활에 실질적인 어려움을 겪는 사용자를 위한 모바일 웹 서비스다.
사용자는 실제 대화를 녹음하거나 업로드하고, 전사와 맥락을 확인한 뒤, **근거 발화가 붙은 대화 리포트**를 받는다.
리포트에서 연습 목표를 고르면 **같은 목표를 유지한 모의 대화**로 연습하고, 첫 시도·힌트·재시도가 기록된다.
기록이 쌓이면 다음 코칭(목표·상황·도움 수준)이 달라진다.
핵심 흐름: 실제 대화 녹음·전사 → 맥락 확인 → 수행 평가·피드백 → 훈련 목표 → 모의 대화·코칭 → 기록·재평가 → 다음 맞춤 코칭

## 2. 대상 사용자

| 역할 | 설명 | MVP 포함 |
|---|---|---|
| 주 사용자 | SCD로 인한 의사소통 어려움이 있는 사용자. 작업 가정: 약 6–12세 아동(세부 연령 미확정) | 포함 |
| 보호자·의사소통 지원자 | 동반 이용, 결과 열람(사용자가 허용한 범위) | 포함(열람 권한 설정만) |
| 전문가 | 모든 세션에 있다고 전제하지 않음 | 제외 |

## 3. 서비스 원칙 (요구사항 전반에 적용)

1. **진단하지 않는다.** SCD 진단, 공식 임상 점수, 중증도, 치료 효과를 산출·표시하지 않는다.
2. **종합점수를 만들지 않는다.** "이번 기회에 목표 행동이 어떻게 나타났는가"를 행동별로 보여준다.
3. **관찰 기회를 먼저 판정한다.** 기회 없음·맥락 부족·전사 불명확·지원하지 않는 매체는 실패가 아니라 별도 상태다.
4. **근거를 붙인다.** 모든 판정은 근거 발화 ID와 판단 이유를 가진다. 근거보다 강한 결론을 쓰지 않는다.
5. **잘한 장면을 함께 보여준다.** 정당한 거절·도움 요청·대화 종료를 자동 실패로 처리하지 않는다.
6. **상대의 속마음을 정답으로 제시하지 않는다.** 한 가지 모범 문장을 강요하지 않고 기능적인 여러 대응을 허용한다.
7. **사용자가 통제한다.** 분석 수정 요청, 목표 변경, 훈련 중단, 기록 삭제가 항상 가능하다.
8. **연결을 유지한다.** 리포트에서 선택한 목표는 목표 ID와 원본 사건 ID를 유지한 채 훈련으로 넘어가고, 훈련 결과도 같은 목표에 연결된다.
9. **독립 수행과 도움 후 수행을 섞지 않는다.** 재시도는 첫 시도를 덮어쓰지 않는다.
10. **전사 속 지시문은 데이터다.** 전사 텍스트를 LLM 시스템 명령으로 취급하지 않는다.

## 4. MVP 범위 (In scope)

| ID | 기능 | 요구사항 요약 | 관련 화면 |
|---|---|---|---|
| F01 | 녹음·전사 | 파일 업로드 또는 브라우저 녹음, 발화별 전사·화자·시간정보, 화자/발화 수정, 불명확 구간 표시, 처리 중/실패/재시도 상태 | A2, A2-R, A3 |
| F02 | 맥락 구조화 | 관계·장소·목적·사용자 목표 입력, 모르는 정보는 "미상"으로 저장, 확인한 내용과 미확인 내용 구분 | A2, A3 |
| F03 | 수행 평가 | 3개 행동 묶음(응답 관련성 / 명료화·대화 수리 / 주제 유지·전환)에 대해 기회 판정 → 행동 판정 → 근거·보류 사유 출력 | A4 |
| F04 | 목표·프로필 | 장면별 어려움과 반복 패턴 구분, 추천 이유와 원인 사건 표시, 사용자 선택 저장 | A5, C2 |
| F05 | 모의 대화 | 검토된 시나리오 원형 + 제한적 변형, 첫 시도·힌트(3단계)·재시도·중단 기록 | B1–B5 |
| F06 | 기록·다음 추천 | 실제 대화/모의 대화 구분, 조건별 추이(기록 부족 시 "비교 불충분"), 추천 이유 표시, 기준·모델 버전 이력 | C1–C4 |
| F07 | 정정·삭제 | 전사 정정 시 관련 판정 재검토 표시, 삭제 요청 시 연결 기록 처리 범위 표시 | A3, C5 |

**테스트 조건**: 모든 데이터는 합성 데이터다(`05_synthetic-test-data.md`). STT·LLM은 인터페이스 뒤의 **Mock 구현을 기본값**으로 하고, 실제 연동 어댑터는 설정으로 교체 가능하게 설계만 한다.

## 5. 범위 제외 (Out of scope)

- SCD 자동진단, 임상 중증도·개선율, 공식 척도(TOPICC, PRS-SA, YiPP, KOPLAC) 자동 점수 및 문항 복제
- 비디오 기반 시선·표정 평가, 정밀 음향 지표
- 청자 지식·함축 응답 행동 평가(확장 단계)
- FAR 상황 자동 생성, 검토되지 않은 완전 자율 훈련 처방
- Vector RAG·GraphRAG, Neo4j 운영 배포
- 전문가 대시보드, 음성 코칭(TTS), 결제·과금
- 실제 사용자 데이터 수집, 사용자 데이터로 모델 재학습
- 네이티브 앱(모바일 웹으로 대체)

## 6. 성공 기준 (이번 테스트)

1. 합성 대화 3건이 업로드 → 전사 확인 → 리포트 → 목표 선택 → 모의 대화 → 기록까지 끊김 없이 이어진다.
2. 리포트의 모든 판정이 유효한 근거 발화 ID를 가진다.
3. 기대 판정(`05`)과 Mock 분석 결과가 일치하고, 보류 사례가 실패로 집계되지 않는다.
4. 재시도가 첫 시도를 덮어쓰지 않고, 독립/도움 후 수행이 분리 집계된다.
5. 전사 정정 시 관련 판정에 "재검토 필요"가 표시되고, 삭제 시 연결 기록이 함께 처리된다.
6. 화면에 금지 표현(7장)이 나오지 않는다.

## 7. 화면 문구 금지 표현

"사회성 부족", "정상/비정상", "점수", "진단", "치료", "상대의 진짜 마음", "정답", "실패했어요"
→ 대신: "이번 대화에서는 ~가 보이지 않았어요", "이렇게 말해볼 수도 있어요", "분석을 보류했어요(이유)"
