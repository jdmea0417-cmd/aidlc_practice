## US1 시작 — Must

### US1.1 첫 방문 서비스 안내에 동의하기

**P1 주 사용자로서** 나는 처음 들어올 때 이 서비스가 무엇이고 무엇이 아닌지 안내를 받고 동의하고 싶다. **그래야** 진단이나 점수를 받는 곳으로 오해하지 않고 안심하고 쓸 수 있다.

- **등급**: Must · **요구사항**: FR9.2 · **화면**: A1 · **의존**: 없음

- **AC1.1.1** Given 동의 전 사용자가, When 앱을 열면, Then 서비스 안내가 먼저 뜨고 "진단이 아님", "녹음·데이터 처리", "이용 한계", "판정 기준은 공식 척도가 아님" 네 내용이 모두 보인다 `[component]` `[e2e:S1]`
- **AC1.1.2** Given 안내 화면에서, When 동의 전에 하단 탭을 누르거나 다른 화면 주소를 직접 입력하면, Then 이동하지 않고 "안내를 읽고 동의하면 쓸 수 있어요"가 보이며 안내 화면에 머문다 `[component]`
- **AC1.1.3** Given 동의를 마친 사용자가, When 앱을 다시 열거나 다른 브라우저로 열면, Then 안내 없이 홈으로 들어간다 — 동의는 사용자 단위로 서버에 저장된다 `[integration]`
- **AC1.1.4** Given 안내 문구가, When 금지 표현 검사를 받으면, Then 금지 표현은 **허용 문장 목록에 등록된 문장**(예: 서비스 안내의 "진단이 아니에요") 안에서만 나타난다. 목록 밖 사용은 0건이다 `[unit]`

INVEST: 독립 — 홈 표시와 분리된 동의 흐름.

### US1.2 홈에서 무엇을 할지 고르기

**P1 주 사용자로서** 나는 홈에서 실제 대화 돌아보기와 모의 대화 연습 중 하나를 고르고 진행 중인 목표와 최근 기록을 보고 싶다. **그래야** 지금 할 일을 바로 시작할 수 있다.

- **등급**: Must · **요구사항**: FR9.1, NFR1, NFR2, NFR9 · **화면**: A1, 하단 탭 · **의존**: US1.1 (화면 이동)

- **AC1.2.1** Given 진행 중인 목표가 있는 사용자가, When 홈을 열면, Then "실제 대화 돌아보기", "모의 대화 연습하기", 진행 중인 목표 카드, 최근 기록 1~2건 요약이 보인다 `[component]`
- **AC1.2.2** Given 기록과 목표가 하나도 없는 사용자가, When 홈을 열면, Then 목표 카드는 나타나지 않고 최근 기록 자리에는 비어 있음 안내가 보인다. 최근 기록을 불러오지 못하면 다시 시도 버튼이 보인다 `[component]`
- **AC1.2.3** Given 375px 폭에서, When 홈과 하단 탭을 표시하면, Then 가로 스크롤이 생기지 않고 모든 탭 버튼의 터치 영역이 44px 이상이다 `[browser]`
- **AC1.2.4** Given 키보드만 쓰는 사용자가, When Tab 키로 홈을 이동하면, Then 모든 카드와 탭에 접근 가능한 이름이 읽히고 Enter 로 선택된다 `[component]`
- **AC1.2.5** Given 홈에서, When 하단 탭 "대화 돌아보기" / "연습" / "기록"을 누르면, Then 각각 실제 대화 목록 / 연습 목록(B1) / 나의 기록(C1)이 열린다. 실제 대화 목록의 항목을 누르면 그 대화의 리포트(A4)가 열리고, 목록 위의 "새 대화 가져오기"는 A2 를 연다 `[component]` — `[Q6]` (D-75)

## US2 대화 가져오기 — Must

### US2.1 음성 파일을 올려 대화 가져오기

**P1 주 사용자로서** 나는 녹음해 둔 대화 파일을 올려 전사를 받고 싶다. **그래야** 무슨 말이 오갔는지 눈으로 확인할 수 있다.

- **등급**: Must · **요구사항**: FR1.1, FR1.3, NFR2, NFR9 · **화면**: A2 · **의존**: US9.1, AC9.2.1, AC9.2.3 (기술 의존). 홈에서의 진입(US1.2)은 화면 이동이라 의존이 아니다 `[contrib:developer]`

- **AC2.1.1** Given 가져오기 화면에서 "대화에 참여한 사람에게 녹음을 알렸어요"에 체크하지 않았을 때, When 파일을 올리려 하면, Then 업로드가 시작되지 않고 확인 체크 안내가 보인다 `[component]`
- **AC2.1.2** Given 확인에 체크하고 음성 파일을 골랐을 때, When 올리면, Then 대화의 상태 값이 `UPLOADING` → `TRANSCRIBING` → `READY` 를 거치고 화면이 그 값을 표시하며, 완료 후 "대화 내용 확인하기"가 활성화된다 (처리 방식은 3.1 이 정한다) `[integration]` `[e2e:S1]`
- **AC2.1.3** Given STT 제공자가 오류를 내는 테스트 대역을 주입했을 때, When 올리면, Then 실패 상태와 "다시 시도" 버튼이 보이고, 안내 문구에 "실패했어요"가 없으며, 다시 시도를 누르면 같은 파일로 전사를 다시 시작한다 `[integration]` `[component]`
- **AC2.1.4** Given 허용되지 않는 형식, 빈 파일, 또는 최대 크기 설정값을 넘는 파일일 때, When 올리면, Then 디스크에 저장되지 않고(크기 초과는 413) 이유가 화면에 표시된다 `[integration]`
- **AC2.1.5** Given 키보드만 쓰는 사용자가, When 알림 확인 체크·파일 선택·"대화 내용 확인하기"를 Tab·Space·Enter 로 조작하면, Then 모두 동작하고 처리 상태의 변화가 화면 읽기 프로그램에 알려진다 `[component]`

### US2.2 브라우저에서 직접 녹음해 가져오기

**P1 주 사용자로서** 나는 파일 없이 브라우저에서 바로 대화를 녹음해 가져오고 싶다. **그래야** 대화가 끝난 자리에서 곧바로 돌아볼 수 있다.

- **등급**: Must · **요구사항**: FR1.2 · **화면**: A2-R · **의존**: US2.1 (같은 업로드·전사 경로)
- **메모**: 축소 압박이 오면 SM1 여섯 단계가 이 스토리보다 우선한다 `[log]` D-43

- **AC2.2.1** Given 알림 확인에 체크하지 않았을 때, When "새로 녹음하기"를 누르면, Then 녹음이 시작되지 않고 확인 안내가 보인다 `[component]`
- **AC2.2.2** Given 마이크 권한을 허용하고 확인에 체크한 사용자가, When 녹음을 시작하면, Then 경과 시간이 표시되고 일시정지·녹음 끝내기·다시 녹음이 동작한다. 마이크 버튼은 접근 가능한 이름과 현재 상태(녹음 중 / 일시정지)를 가진다 `[component]`

### US7.2 목표별 추이를 독립·도움 후로 나눠 보기

**P1 주 사용자로서** 나는 목표별 추이를 혼자 한 것과 도움을 받은 것으로 나눠 보고, 기록이 부족하면 부족하다고 알려 주기를 원한다. **그래야** 섞인 숫자에 속지 않고 실제로 나아지는지 안다.

## US10 상세 조회 — Should

### US10.1 목표 상세와 시도 이력 보기

**P1 주 사용자로서** 나는 한 목표의 원본 장면과 연습 이력을 한 화면에서 보고 목표를 바꾸거나 그만하고 싶다. **그래야** 지금 무엇을 연습하고 있는지와 어떻게 해 왔는지 안다.

- **등급**: Should · **요구사항**: FR12.1 · **화면**: C2 · **의존**: US7.1

- **AC10.1.1** Given 연습 이력이 있는 목표에서, When C2 를 열면, Then 목표 설명·원본 실제 대화 장면·시도 이력 타임라인이 보인다 `[component]`
- **AC10.1.2** Given 기록이 부족할 때, When C2 를 열면, Then 반복 패턴과 잘 된 조건이 표시되지 않는다 `[component]`
- **AC10.1.3** Given C2 에서, When "이 목표 그만하기"를 누르면, Then 목표 상태가 끝남으로 바뀌고 홈의 진행 중 목표 카드에서 빠진다 `[integration]`
- **AC10.1.4** Given 원본 대화가 삭제되어 원본 연결이 비어 있는 목표에서, When C2 를 열면, Then 원본 장면 자리에 "원본 대화가 삭제되었어요"가 보이고 오류가 나지 않는다 `[component]`

### US10.2 연습 기록 상세 보기

**P1 주 사용자로서** 나는 한 번의 연습에서 시도 순서, 받은 힌트, 멈춘 기록을 자세히 보고 싶다. **그래야** 어느 도움에서 달라졌는지 돌아볼 수 있다.

- **등급**: Should · **요구사항**: FR12.2 · **화면**: C3 · **의존**: US6.5

- **AC10.2.1** Given S1 연습 세션에서, When C3 를 열면, Then 시도 2개가 순서대로 독립 / 도움 후 구분, 힌트 단계와 함께 보인다 `[component]`
- **AC10.2.2** Given 중단 후 재개한 세션에서, When C3 를 열면, Then 중단·재개 여부가 표시된다 `[component]`
- **AC10.2.3** Given C3 에서, When 시나리오 정보를 보면, Then 사용된 원형과 변형 정보가 보인다 `[component]`
- **AC10.2.4** Given 시도가 1개(재시도 없음)인 세션에서, When C3 를 열면, Then 다시 시도 자리가 비어 있음 상태로 보인다 `[component]`

### US10.3 실제 대화 기록 상세와 정정 이력 보기

**P1 주 사용자로서** 나는 실제 대화의 정정 반영 전사, 정정 이력, 당시 리포트와 분석 버전을 보고 여기서도 다시 분석하거나 삭제하고 싶다. **그래야** 한 대화의 모든 것을 한곳에서 관리한다.

- **등급**: Should · **요구사항**: FR12.3 · **화면**: C4 · **의존**: US3.3, US8.1

- **AC10.3.1** Given 정정한 S3 에서, When C4 를 열면, Then 정정 반영 전사와 정정 이력 2건, 당시 리포트의 재검토 필요 배지가 보인다 `[component]`
- **AC10.3.2** Given C4 에서, When 분석 기준·모델 버전을 보면, Then 판정에 저장된 버전이 작게 표시된다 `[component]`
- **AC10.3.3** Given C4 에서, When "다시 분석하기"를 누르면, Then A3 의 재분석과 같은 결과(새 분석 회차 추가, 이전 판정 대체됨으로 유지)가 된다 `[integration]`
- **AC10.3.4** Given C4 에서, When "이 기록 삭제"를 누르면, Then US8.1 의 미리보기 흐름으로 이어진다. Given 원음만 삭제된 대화면, Then 전사·리포트는 보이고 원음 재생 자리에는 삭제됨 안내가 보인다 `[component]`

## US12 보호자·공유 — Should

### US12.1 보호자를 초대하고 열람 권한 정하기

**P1 주 사용자로서** 나는 보호자를 초대하고 볼 수 있는 범위를 끄기 / 요약만 / 전체 중에서 직접 정하고 싶다. **그래야** 누가 무엇을 보는지 내가 통제한다.

- **등급**: Should · **요구사항**: FR14.1, FR14.2 · **화면**: C5 나머지 · **의존**: US11.1

- **AC12.1.1** Given 사용자가, When 보호자를 초대하면, Then 초대 코드가 만들어지고 새 연결의 권한은 NONE 이다 `[integration]`
- **AC12.1.2** Given 보호자가 초대 코드로 자기 계정에 연결했을 때, When 사용자가 권한을 SUMMARY 나 FULL 로 바꾸면, Then 바뀐 권한이 저장된다 `[integration]`
- **AC12.1.3** Given 보호자가, When 자기 권한을 바꾸려 하면, Then 거부된다 `[integration]`
- **AC12.1.4** Given 초대를 수락하지 않은 보호자가, When 사용자 정보를 요청하면, Then 아무것도 볼 수 없다 `[integration]`

### US12.2 보호자로서 허락된 범위만 열람하기

**P2 보호자로서** 나는 사용자가 허락한 범위에서 목표와 추이, 허락되면 리포트까지 읽기 전용으로 보고 싶다. **그래야** 아이가 무엇을 연습하는지 알면서도 허락 없는 것은 보지 않는다.

- **등급**: Should · **요구사항**: FR14.3, FR14.4 · **화면**: 보호자 전용 읽기 화면(신규) · **의존**: US12.1

- **AC12.2.1** Given SUMMARY 권한의 보호자가, When 보호자 화면을 열면, Then 목표와 목표별 추이만 보이고 리포트 요청은 거부된다 `[integration]`
- **AC12.2.2** Given FULL 권한의 보호자가, When 보호자 화면을 열면, Then 리포트까지 보이지만 전사 원문과 원음 요청은 거부된다 `[integration]`
- **AC12.2.3** Given NONE 권한의 보호자가, When 보호자 화면을 열면, Then 볼 수 있는 내용이 없다는 안내만 보인다 `[component]`
- **AC12.2.4** Given 보호자 화면에서, When 동작을 찾으면, Then 수정·삭제·연습 시작 동작이 없다 `[component]`

### US12.3 원음 보관 기간 정하고 서비스 안내 다시 보기

**P1 주 사용자로서** 나는 원음을 얼마나 보관할지 정하고 서비스 안내를 다시 보고 싶다. **그래야** 내 데이터가 얼마나 남는지 알고 조절할 수 있다.

- **등급**: Should · **요구사항**: FR14.5 · **화면**: C5 나머지 · **의존**: US1.1

- **AC12.3.1** Given C5 에서, When 원음 보관 기간을 보면, Then 설정값 기본 30일이 보인다 `[component]`
- **AC12.3.2** Given C5 에서, When 보관 기간을 바꿔 저장하면, Then 이후 대화의 보관 만료일이 새 값으로 계산된다 `[integration]`
- **AC12.3.3** Given 보관 기간에 0 이하나 허용 범위 밖 값을 넣었을 때, When 저장하면, Then 저장되지 않고 이유가 보인다 `[component]`

## US13 노트북 레이아웃 — Should

### US13.1 노트북 브라우저에서도 제대로 보기

**P1 주 사용자로서** 나는 노트북 브라우저에서도 화면이 잘리거나 겹치지 않게 보고 싶다. **그래야** 휴대폰이 아닌 기기에서도 쓸 수 있다.

- **AC13.1.3** Given 노트북 폭에서, When 시연 리허설로 SM1 흐름을 한 번 돌리면, Then 끊김 없이 기록까지 도착한다 `[rehearsal]`

- **AC14.1.2** Given 도움 후 시도가 OBSERVED 인 목표가 있을 때, When 추천을 계산하면, Then "도움을 줄여 다시 해 보기"가 추천 이유에 반영된다 `[unit]`
