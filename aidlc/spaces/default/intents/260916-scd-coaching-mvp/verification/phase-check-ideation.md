| 4 | 규제 항목 미기록(D-34) vs F07·보호자 권한 유지 | **모순 아님** — 규제 프레임워크와 제품 기능을 구분해 기록했고 통합 요약에서 확인받았다 |

| 9 | GitHub Actions 사용(TC-16) vs 클라우드 배포 없음(SC-01) | **모순 아님** — Actions 는 배포가 아니라 검사다. 제약 등록부에 구분선을 함께 적었다 |
| 10 | Must 비율 73% vs 프레임워크 권고 60% | **모순 아님** — 지침 초과이며 결함이 아니다. 초과 사실과 이유를 작업 목록 §2 와 초안 요약서 §5 에 의도된 것으로 적었다 |
| 11 | 도구 확정(D-54) vs 초안 요약서의 "2.2 또는 2.6 에서 닫힌다" 서술 | **해소됨** — 초안 요약서 §10 을 "이미 닫혔다"로 갱신했다 |
